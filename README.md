# CodeSpace — مساحة المطور

تطبيق ويب محلي لإدارة المشاريع وملفات الأكواد وتحريرها ومعاينة صفحات الويب. يحافظ على هيكل الملفات الأساسي: `index.html` للواجهة، `src/styles/app.css` للتنسيق، `src/app.js` لمنطق التطبيق، مع `manifest.json` وService Worker.

## التشغيل

افتح `index.html` في متصفح حديث. للحصول على أفضل دعم للتثبيت وService Worker شغّل من خادم محلي مثل:

```bash
python3 -m http.server 8080
```

ثم افتح `http://localhost:8080`.

## التخزين والخصوصية

تُحفظ المشاريع والملفات في IndexedDB محلياً داخل المتصفح، ولا يتم إرسالها إلى خادم. استخدم «تصدير نسخة احتياطية» لحفظ نسخة JSON خارج المتصفح. حذف بيانات الموقع قد يحذف المشاريع المحلية.

## الميزات

- إنشاء مشاريع بقوالب ويب أو JavaScript أو فارغة.
- ملفات ومجلدات ومسارات متداخلة، ورفع ملفات أو مجلدات.
- محرر كبير مع أرقام أسطر، تبويب، حفظ تلقائي، وتنسيق أساسي.
- معاينة HTML داخل iframe مع دمج ملف CSS وJavaScript الشائعين.
- تنزيل ملف، تصدير المشروع، واستيراد/تصدير نسخة احتياطية.
- واجهة متجاوبة ومظهر فاتح/داكن.

ملاحظة: هذه بيئة تطوير محلية للمتصفح وليست خدمة Git مستضافة؛ لا تتوفر مزامنة بين الأجهزة أو تنفيذ خوادم/بناء APK.
